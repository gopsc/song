# 这是一个音符脚本示例
# 可以使用 @WAVEFORM 或 @波形名 来切换默认波形
# 可以在文件开头、中间任意位置切换波形

# 设置初始波形为方波
@WAVEFORM square

# 第一段：使用方波演奏小星星
C4-4 G4-4 A4-4 G4-4
F4-4 E4-4 D4-4 C4-4

# 切换到锯齿波
@sawtooth

# 第二段：使用锯齿波演奏
G4-4 F4-4 E4-4 D4-4
C4-4 G4-4 E4-4 C4-4

# 切换到三角波
@triangle

# 第三段：使用三角波演奏
C5-8 C5-8 G4-8 G4-8 A4-8 A4-8 G4-4
F4-8 F4-8 E4-8 E4-8 D4-8 D4-8 C4-4

# 切换回正弦波
@sine

# 第四段：使用正弦波，并指定不同时值
C4-4 D4-4 E4-8 F4-8 G4-4 A4-4 B4-4 C5-4

# 最后再次切换回方波
@square

# 结尾部分
G4-4 E4-4 C4-2
R-4  # 休止符
C4-8 C4-8 C4-4
