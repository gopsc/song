# 复杂示例：在同一行内也可以切换波形
# 使用 @波形名 在行内切换

@square
# 开头使用方波
C4-4 D4-4 E4-4 F4-4

@sawtooth
# 切换到锯齿波
G4-4 A4-4 B4-4 C5-4

# 在同一行中混合不同波形的音符
C5-4-square G4-4-sawtooth E4-4-triangle C4-4-sine

# 使用不同时值
C4-8 D4-8 E4-8 F4-8 G4-8 A4-8 B4-8 C5-8
C5-16 B4-16 A4-16 G4-16 F4-16 E4-16 D4-16 C4-16

@triangle
# 使用三角波演奏和弦进行
C4-4 E4-4 G4-4 C5-4
F4-4 A4-4 C5-4 F5-4
G4-4 B4-4 D5-4 G5-4
C4-4 E4-4 G4-4 C5-4

@sine
# 结束部分
C5-2 R-4 C4-2
